## Junior Foundation Checklist (know these well)

**Java core**
- [ ] 8 primitives + wrappers; autoboxing pitfalls; String pool/interning
- [ ] Collections + their Big-O; how HashMap works internally (hash → bucket → equals)
- [ ] `equals()`/`hashCode()` contract
- [ ] Exceptions (checked vs unchecked, try-with-resources)
- [ ] Generics basics (wildcards, bounded types) and Streams + lambdas
- [ ] Optional (correct use vs `.get()` anti-pattern)
- [ ] Records, sealed classes, pattern matching (modern Java awareness)

**Spring Boot**
- [ ] REST controllers, dependency injection (constructor injection), `@Service`/`@Repository`
- [ ] Spring Data JPA (entities, repositories, relationships, LAZY vs EAGER, N+1)
- [ ] Bean validation, global exception handling (`@RestControllerAdvice`)
- [ ] Configuration & profiles, basic Spring Security + JWT

**Surrounding skills**
- [ ] SQL (CRUD, joins, indexes, transactions/ACID)
- [ ] HTTP/REST fundamentals, status codes, DTOs
- [ ] Git workflow, Maven basics, Docker basics
- [ ] JUnit 5 + Mockito testing
- [ ] Frontend basics (HTML, CSS, JavaScript, React)

> **Mindset that still applies now:** debug your own code, ask *why* it works, and if you can't explain it, you don't fully know it yet.
